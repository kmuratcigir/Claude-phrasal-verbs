How it would be counted

  • The naturalness check already runs spaCy. A new script lists every word + preposition you say ("invest in", "angry with", "on Monday"). Nothing new to install.
  • A use is wrong if the check flagged it as a preposition slip, and right otherwise. A dropped preposition ("wait them") comes from the flags.
  • Accuracy counts voice only, like the chunks. Plain "to" before a verb ("want to go") is never counted.
  • Accuracy can read a little high: a slip the check misses counts as right.
  • This tab reads only the Ledger. The quiz stays separate.
